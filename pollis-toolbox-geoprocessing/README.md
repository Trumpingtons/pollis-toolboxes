# Geoprocessing Toolbox

**Geoprocessing: Calculations on Rasters and Elevation Models.** Map algebra on grids of cells, and the measures of the land surface that come from an elevation model, written in Julia and each checked against R, or against Python's Relief Visualization Toolbox (RVT). For analysts who compute with rasters, in geography, hydrology, ecology, planning, regional science and archaeology.

Installing it adds the **Geoprocessing** submenu to the end of the **Extend** menu; its **Edit** button in the Installed section of the Extensions pane moves it, or any of its panels, to another menu. Each panel has key points, a decision table, example code you can send to the Julia REPL or a notebook, reference wikis, and Next Steps that replicate its results against R or RVT.

The menu has Grid Calculations and Terrain and Elevation Analysis; then the submenus Satellite Indicators and Lidar and 3D Scans, whose items are greyed, and Archaeological Prospection, which holds Relief Visualisation, Candidate Features, Learned Detection in Lidar, and the greyed Learned Detection in Satellite Images; then Coordinate Transformations and Projections and Spatial Indexing, greyed. One menu item per panel, which opens on its first tab.

The [Smart Regions Toolbox](../pollis-toolbox-smart-regions/README.md) reads raster and vector files and downloads elevation models and satellite images; the [Spatial Econometrics Toolbox](../pollis-toolbox-spatial-econometrics/README.md) models data on areas.

## Requirements

Julia. Each panel lists the Julia packages it uses on its Powered by line and offers to install the missing ones. Grid Calculations reads area files through DuckDB's spatial extension, which Pollis downloads from DuckDB's repository when the toolbox is installed, and keeps if the toolbox is uninstalled. The panels need the internet only for their example files, which they keep in their Folder.
