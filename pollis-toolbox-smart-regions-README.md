# Smart Regions Toolbox

Version 0.1.41

**Smart Regions: Spatiotemporal Infrastructure, Pollution and Climate.** Tools for municipalities and regional authorities that manage physical infrastructure and environmental systems, in Smart Cities (dense transit networks, metropolitan air quality) and Smart Rural Areas (low-density municipalities, watersheds, aquifers, regional supply grids), where human activity, infrastructure and climate interact across scales.

Installing it adds the **Smart Regions** submenu to the end of the **Extend** menu; its **Edit** button in the Installed section of the Extensions pane moves it, or any of its panels, to another menu. Each panel has key points, a decision table, example code you can send to the Julia REPL or a notebook, reference wikis and notebook tutorials.

The menu is organised by the kind of data: Places and Features has Geospatial Vector Files, OpenStreetMap Data and Overture Maps Data; Boundaries and Statistical Units has Eurostat GISCO and INSPIRE Data; Images and Elevation has Raster Files, Copernicus Data Space, USGS EarthExplorer, OpenTopography and Mapillary Street-Level Imagery; Networks has Transport Network Files, Route and Network Analysis, Mobility and Flows and Air Traffic; City Objects and 3D has City Model Files and Point Cloud Files; and Maps and Layers has OpenStreetMap Base Map, Copernicus Imagery Layers and Mapillary Street-Level Viewer, then Google Maps and Google Photorealistic 3D Maps. Smart Cities and Smart Rural Areas follow. One menu item per panel, which opens on its first tab. The base maps come from OpenFreeMap's vector tiles of OpenStreetMap data, free and without an API key, and need the internet. The Copernicus imagery layers come from the tile and map services of EOX IT Services and the European Environment Agency, also without an API key.

## Requirements

Julia. Each panel lists the Julia packages it uses on its Powered by line and offers to install the missing ones. The panels read vector files through DuckDB's spatial extension, and Overture Maps and Eurostat GISCO read files over HTTPS through its httpfs extension, which Pollis downloads from DuckDB's repository when the toolbox is installed, and keeps if the toolbox is uninstalled. OpenStreetMap Data, Overture Maps, Eurostat GISCO, INSPIRE Data, Copernicus Data Space, USGS EarthExplorer, OpenTopography, Mapillary Street-Level Imagery, Mapillary Street-Level Viewer, Route and Network Analysis, Mobility and Flows and OpenSky Network need the internet; OpenStreetMap Data's Geofabrik tabs, Eurostat GISCO, INSPIRE Data, Copernicus Data Space, USGS EarthExplorer, OpenTopography, Mapillary Street-Level Imagery, Route and Network Analysis, Mobility and Flows and OpenSky Network keep the files they download in their Folder. Copernicus Data Space needs a free account of the Copernicus Data Space Ecosystem to download (not to search), and USGS EarthExplorer an account of the USGS EROS Registration System with access to its Machine-to-Machine API and an application token, OpenTopography a free OpenTopography API key to download (not to search), Mapillary Street-Level Imagery and Mapillary Street-Level Viewer a Mapillary client access token for every tab, Mobility and Flows an LTA DataMall account key for Singapore only, and OpenSky Network an OpenSky API client for Flights by Airport and past tracks; each panel asks for them with the key on its Powered by line and Pollis keeps them in its Secret Storage.
