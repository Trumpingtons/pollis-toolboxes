# Self-Study: Learn and Practise

Version 0.1.5

Turn your slides, notes and PDFs into what helps you study: more problems with their solutions, a topic explained in depth, a summary of a paper, prose and audio from slides, or slides from a long text. For students, and for teachers preparing their classes.

Installing it adds the **Self-Study: Learn and Practise** submenu to the end of the **Extend** menu; its **Edit** button in the Installed section of the Extensions pane moves it, or any of its panels, to another menu. Each panel has key points, a decision table, example code you can send to the Julia REPL or a notebook, reference wikis and notebook tutorials.

## Panels

| Panel | What it covers | Powered by |
|---|---|---|
| Practice | Multiple-choice exercises on descriptive statistics, hypothesis tests and linear regression, new data for each seed, with checked answers and explanations | [Distributions.jl](https://github.com/JuliaStats/Distributions.jl) |
| Write an Exercise | A template for new exercises, computed from data or conceptual, with previews of their versions and a check that no two choices coincide | [Distributions.jl](https://github.com/JuliaStats/Distributions.jl) |

## Requirements

Pollis and Julia. Each panel lists the Julia packages it uses on its Powered by line and offers to install the missing ones.
